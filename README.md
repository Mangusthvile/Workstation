# Workstation

A desktop-style writing workstation that runs in the browser. Four draggable windows share one desktop:

- **Text Editor**: nine toggleable revision rules (proofreading, flow, lore rules, section splitting and more) sent to Gemini through the local server. Em dashes are stripped everywhere.
- **World Clock**: progress tracker for story events, quests and quotas, with thresholds, repeatable cycles and a Chronicle of completed events.
- **Dice Roller**: multiple dice groups, each with its own modifier and label.
- **Quick Scratchpad**: a plain notes pad.

Everything is saved in the browser automatically. **Ctrl+S** saves a full checkpoint, and the folder icon in the menu bar restores it or exports/imports a `.json` backup.

## Desktop app (Windows)

Download `Workstation.exe` from the [Releases page](../../releases) and double-click it. No install and no Node.js needed.

- The first launch asks for a Gemini API key (only needed for AI editing; press Enter to skip). It is saved in `%LOCALAPPDATA%\Workstation\settings.env`, which you can edit with Notepad any time.
- Workstation opens in its own window (Microsoft Edge or Chrome app mode, falling back to your default browser) at `http://localhost:3777`.
- A small console window stays open while it runs and closes by itself when you close the Workstation window. Double-clicking again while it runs just opens another window.
- Your work is saved in that window's own browser profile under `%LOCALAPPDATA%\Workstation`. To bring work over from the web version, use Save & Load > Download Backup there, then Upload & Load in the desktop app.
- Windows may show "Windows protected your PC" the first time because the exe is not code-signed. Click **More info > Run anyway**.

To build the exe yourself: install [Bun](https://bun.sh) (`npm i -g bun`), then run `npm run build:exe`. The result is `release/Workstation.exe`, with the Workstation icon and version info. Bun cross-compiles, so this works on Windows, macOS or Linux.

The icons (exe icon, browser/app window icon, menu bar logo) all come from one design in `scripts/icon/make-icons.py`. Edit it and run `python3 scripts/icon/make-icons.py` (needs Playwright) to regenerate `public/` icons and `desktop/icon.ico`.

## Running from source

Requires Node 20 or newer.

```bash
npm install
cp .env.example .env      # then put your key in GEMINI_API_KEY
npm run dev               # http://localhost:3000
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Express + Vite dev server with hot reload |
| `npm run build` | Production build into `dist/` |
| `NODE_ENV=production npm start` | Serves `dist/` and the API (run `build` first) |
| `npm test` | Unit tests for the editing engine, diff, sanitizer and World Clock rules |
| `npm run build:exe` | Builds `release/Workstation.exe` (needs Bun) |
| `npm run lint` | Type-check |

## Layout

```
server.ts                    Web server: Vite in development, dist/ in production
server/app.ts                The API (/api/edit, /api/health), shared by web and desktop
server/editEngine.ts         Prompt building, section parsing, retry rules (pure, tested)
desktop/launcher.ts          Entry point of Workstation.exe
desktop/icon.ico             Exe icon (generated by scripts/icon/make-icons.py)
scripts/build-exe.mjs        Builds the exe (vite build, embed dist/, bun compile)
src/
  components/
    Desktop.tsx              Menu bar, dock, window stacking, save/load
    desktop/                 Snapshot format, Save & Load modal, menu bar clock
    window/WindowFrame.tsx   Shared draggable/resizable window used by every widget
    TextEditorWidget.tsx     Editor window
    Toolbar.tsx              The nine rule buttons (defined as data)
    OutputViewer.tsx         Result tabs: sections, full text, diff, applied rules
    DiceRollerWidget.tsx
    ScratchpadWidget.tsx
    eventTracker/            World Clock, split by concern:
      state.ts               Reducer: every World Clock action in one place
      logic.ts               Pure rules: progression, cycles, filters, summaries
      EventCard.tsx / HistoryCard.tsx / EventForm.tsx / ProgressDisplay.tsx / parts.tsx
  lib/                       Storage keys and debounced writes, shared hooks, browser helpers
  editPresets.ts             Toolbar presets
  textSanitizer.ts           Em dash removal (shared by browser and server)
  diffUtil.ts                Word-level Myers diff
tests/                       node:test suites (run with npm test)
```
